A tiny program that writes one absurd invention pitch to a text file. The
pitch is a single sentence of at most 220 characters: a ridiculous invention
that fixes a tiny everyday annoyance — a washing machine that puts a stray
red sock on trial.

## Run it

```sh
python3 main.py
```

It writes the pitch to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
